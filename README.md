# Roblox Live Bootstrapper
it just a tool that re-install roblox to be always live.
u need to run the tool for the installation process so its not a auto detection for the channel.
its pretty useful tho (: at least for me



Download
[**here**](https://github.com/ayment/Roblox-force-channel/releases/download/roblox-force/net8.0-windows.rar)  


or Build It Yourself (:


If you want to reset Roblox LIVE Launcher and remove its shortcuts, run the following commands in Command Prompt (cmd)
```
del "%LOCALAPPDATA%\RobloxLiveLauncher\Config.json" /F /Q 2>nul
del "%APPDATA%\RobloxLiveBootstrapper\settings.json" /F /Q 2>nul
del "%USERPROFILE%\Desktop\Roblox LIVE.lnk" /F /Q 2>nul
rmdir "%APPDATA%\Microsoft\Windows\Start Menu\Programs\Roblox LIVE" /S /Q 2>nul
```
